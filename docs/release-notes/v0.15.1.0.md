## StemScribe v0.15.1.0：修复「修完反而变差」+ 提速 + 分轨多选

### 修复后听感变差的问题
用户反馈：有的歌修复后 AI 评分下降（7.16 → 6.78），听感也明显变差。逐个模块排查后找到原因：
- **「人声清理」误伤了正常的泛音。** 共振抑制器原来逐帧比较频谱，人声和乐器正常的泛音本来就比周围高 6–15 dB，被它当成刺耳共振压掉了，结果 2.5–9 kHz 发闷、发水。现在改成只检测**持续存在**的共振（按 300 ms 平均后再判断），这部分损失降到原来的约五分之一。
- **去齿音只在真有齿音尖峰时才工作。** 原来它不管有没有问题，总会处理约 15% 的时间。
- **新增「处理过度」保护**（需要安装 AI 音质评分模型）：修复后如果评分比原曲低 0.1 以上，会自动减半处理再试；还不行就只做响度和峰值。原曲本来就不错的歌，不会再被越修越差。
- 规则评分新增「中高频损失」一项，能发现处理后变闷的情况。

实测（标准档）：

| 歌曲 | AI 评分 修复前 → 修复后 | 结果 |
| --- | --- | --- |
| 辽水之源 | 7.16 → 7.15（上一版 6.78） | 原曲质量不错，只做了响度和峰值 |
| 东北的东 | 7.23 → 7.32 | 2 kHz 刺耳峰消除 |
| 11月9日 | 7.95 → 7.93 | 没有问题需要修 |
| MiniMax | 7.72 → 7.67 | 3.6 kHz 严重刺耳峰（+7.2 dB）消除 |

### 更快
- 限制器从最多 4 遍处理改为 1 遍加整体微调，母带粘合压缩和多处立体声处理也做了优化，听感上没有任何变化。
- 一首 4 分钟的歌，修复（不含分轨）约 50 秒，包括 AI 评分。

### 其他修复
- **导入分轨支持多选**：按住 ⌘ 或 ⇧ 可以一次选多个文件，也可以「继续添加」或删掉某一条。
- **分轨文件按歌曲分开保存**：原来所有歌的分轨都存在同一个临时目录里，处理新歌时会覆盖旧的；已保存的工程可能会指向别的歌的分轨。现在每首歌单独存一个目录，再次分轨同一首歌直接复用。打开旧工程时，如果分轨文件已失效，会提示「请重新分轨」。

## 下载安装（macOS 13+，Apple Silicon M1/M2/M3/M4）

1. 下载下方的 `StemScribe_0.15.1.0_aarch64.dmg`，打开后把 StemScribe 拖进「应用程序」。
2. 这是 ad-hoc 签名的预发布版，没有经过 Apple 公证，首次打开会被拦截：
   - 打开「系统设置 → 隐私与安全性」，在页面底部点「仍要打开」；或者
   - 在终端执行 `/usr/bin/xattr -d com.apple.quarantine /Applications/StemScribe.app`
3. 建议在「设置 → 本地模型」里下载「Audiobox 音质评委」（约 126 MB），开启处理过度保护。
