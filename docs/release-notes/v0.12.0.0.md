## StemScribe v0.12.0.0：可选的高质量分轨

### 高质量分轨（可选，默认关闭）
- 新增 **HTDemucs-FT 人声专家模型**（Meta 精调版，MIT 协议，约 166 MB）。在「设置 → 本地模型」里打开「高质量分轨」后，AI 分轨、一键扒带、一键修复都会额外用它重新分离人声。
- 只替换人声轨，四轨相加的总和和标准分轨完全一致，所以修复引擎「只叠加改动量」的保证不受影响。
- 实测：人声乐句间隙的底噪更低（−51.1 → −53.9 dB，−60.8 → −65.9 dB），低频串音也略少。代价是分轨时间大约翻倍，本来就分得很干净的歌几乎没有差别。

### 关于 AI 修复模型的评估结论
这一版评估了几种 AI 音质修复和分轨模型，结论如下：

| 模型 | 结论 | 原因 |
| --- | --- | --- |
| HTDemucs-FT（人声专家） | 已接入（可选） | MIT 协议，和现有模型输入输出一致，人声更干净 |
| Apollo（MP3 修复） | 暂不接入 | 官方模型只针对 128 kbps 以下的 MP3，对 WAV 和 320k MP3 没用；社区的通用版没有任何许可证 |
| UniverSR（补高频） | 暂不接入 | 第三方测试显示通用模型只在 8 kHz 频宽的输入上表现正常，对 AI 歌（14–20 kHz）不适用；也没有 ONNX 版本 |
| BS-RoFormer（分轨） | 暂不接入 | 可用的权重没有明确许可证，或者是 GPL 协议 |

补高频继续使用内置的激励器，它会根据检测到的截止频率自动生成泛音。

## 下载安装（macOS 13+，Apple Silicon M1/M2/M3/M4）

1. 下载下方的 `StemScribe_0.12.0.0_aarch64.dmg`，打开后把 StemScribe 拖进「应用程序」。
2. 这是 ad-hoc 签名的预发布版，没有经过 Apple 公证，首次打开会被拦截：
   - 打开「系统设置 → 隐私与安全性」，在页面底部点「仍要打开」；或者
   - 在终端执行 `/usr/bin/xattr -d com.apple.quarantine /Applications/StemScribe.app`
3. 第一次用「一键修复」时，按提示下载 AI 分轨模型（约 166 MB，只需一次）。高质量分轨需要额外下载约 166 MB。
