## StemScribe v0.11.0.0：参考曲匹配 + 鼓替换（实验性）

### 参考曲匹配
在「修复」页选一首你喜欢的歌当参考，修复时会把你的歌往参考曲的声音上靠：
- **频响**：中声道按 1/3 倍频程平滑后匹配，最多 ±6 dB；侧声道（立体声宽度）按倍频程匹配，最多 ±4 dB，只作用在 150 Hz 以上。
- **线性相位处理**：不会改变相位，也不会让声音整体偏移。高频截止以上不强行提升，交给「补高频」处理。
- **跟随参考响度**（可选）：目标响度改成参考曲的响度，范围限制在 −16 到 −9 LUFS。
- 匹配强度默认 70%，避免把编曲不同的两首歌硬拉成一样。

实测（参考曲为一首分轨精修的 24-bit 母带，标准档）：

| 歌曲 | 与参考的频响差距（1/3 倍频程） | 倍频程复核（ffmpeg 独立测量） |
| --- | --- | --- |
| Suno 3 分 32 秒 | 3.85 → 1.84 dB | 2.79 → 0.24 dB |
| Suno Remastered 4 分 02 秒 | 3.28 → 1.22 dB | 1.72 → 0.26 dB |

两首的响度都做到 −14.0 LUFS、峰值 −1.0 dBTP，动态没有变平。

### 鼓替换（实验性，默认关闭）
- 在高级选项里打开后，StemScribe 会识别鼓轨里的底鼓和军鼓，用真实的原声鼓采样按原力度叠加上去，让 AI 鼓更有冲击力。叠加比例 30% / 50% / 80% 可选。
- 鼓点会经过几道筛选：太弱的不叠加，不在节拍网格上的不叠加，同一个军鼓重复触发只保留一次。如果整首歌的鼓点不够规整，会自动跳过并告诉你原因。
- 踩镲暂时不叠加。AI 鼓轨里的踩镲和金属声混在一起，识别还不够可靠。
- 鼓采样来自 Big Rusty Drums（Karoryfer Samples，CC0 公有领域授权），已内置在 App 里，共 2.9 MB。

## 下载安装（macOS 13+，Apple Silicon M1/M2/M3/M4）

1. 下载下方的 `StemScribe_0.11.0.0_aarch64.dmg`，打开后把 StemScribe 拖进「应用程序」。
2. 这是 ad-hoc 签名的预发布版，没有经过 Apple 公证，首次打开会被拦截：
   - 打开「系统设置 → 隐私与安全性」，在页面底部点「仍要打开」；或者
   - 在终端执行 `/usr/bin/xattr -d com.apple.quarantine /Applications/StemScribe.app`
3. 第一次用「一键修复」时，按提示下载 AI 分轨模型（约 166 MB，只需一次）。
